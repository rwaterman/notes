# Static Site Generators

Publishing Markdown / Obsidian (and possibly org-mode) as a site. This KB runs on **Quartz**.

| | Astro | Hugo | Quartz |
|---|---|---|---|
| Fit | Personal/professional site, blog, portfolio | Durable, boring, long-lived publishing | Obsidian-native digital garden |
| Strengths | Modern TypeScript stack, components, DX | Very fast builds, minimal churn, Markdown **and** org-mode | Backlinks, graph, wikilinks, search, popovers out of the box |
| Weaknesses | Not Obsidian-native; org-mode needs conversion | Older templating / content model | Specialized; awkward for custom pages |

```text
Professional dev site + blog        → Astro
Public Obsidian / digital garden    → Quartz
Durable Markdown/org-mode publisher → Hugo
```
